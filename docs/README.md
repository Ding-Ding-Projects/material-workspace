# Documentation

One article per feature, grouped by category. Each article covers what the
feature does, how it is configured, how it fails, what it means for your
privacy and security, and how to verify it yourself.

| Category | What is in it |
| --- | --- |
| [Saving](features/saving/README.md) | Autosave, document history, restoring |
| [Interface](features/interface/README.md) | Tabs, search, the regex builder, the command palette |
| [Language](features/language/README.md) | Language modes, funny levels, personal vocabulary |
| [Building](features/building/README.md) | Building from source, packaging, releases |

## A note on what is documented

Articles describe what this application **actually does today**. Where a feature
is not built yet, its article says so plainly rather than describing an intention
in the present tense. A document that is confidently wrong is worse than a
missing one, because a reader has no way to tell.
