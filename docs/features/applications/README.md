## What "built and verified" means here

Each application has its own engine tests and its own set of checks driven
against the **real built window** — not a mounted component, not a mock. The
counts are in each article.

## And what each still lacks

Every one of them is honest about what it does not do yet: in its own article,
and on its own surface wherever a missing capability would otherwise look like
a defect. PDF says outright that it does not render pages rather than showing a
grey rectangle; Draw says it has no resize handles; Notes says nothing survives
a restart yet.

An honest absence costs a reader a sentence. A decorative control costs them
the time it takes to discover it is empty, and their trust in everything beside
it.
