## The rule they all share

**Every one of them reports rather than acts.** Nothing deletes, nothing blocks
silently, nothing changes a label on its own.

That is not timidity. An automatic governance action is unrecoverable by
definition — the deleted record is gone, the lowered label cannot be un-seen —
and a system people route around because it acted on its own is worse than no
system at all.

## Not built yet

Policy distribution from a server, per-user authority beyond a single flag,
signature generation and verification, and applying a label to a real document
rather than to the panel's own example.
