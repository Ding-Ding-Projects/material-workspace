# Saving

How Material Workspace keeps your work, and how you get an earlier version back.

| Article | Status |
| --- | --- |
| [Autosave and document history](autosave-and-history.md) | Built and verified |
| [Document history panel](history-panel.md) | Not built yet |

The short version: saving is continuous, history is append-only, and the
repository that holds it lives beside the application's own data rather than
inside any folder of yours.
